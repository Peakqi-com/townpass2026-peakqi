# 補助小幫手研究：臺北市長輩、身障者可申請的補助（資格、金額、申請管道、代辦）

> 整理日期：2026-11-07（比賽當天，民國 115 年）。給長輩模式的「補助小幫手」用：先用幾個大按鈕問題篩選，再列出「您可能可以申請」的補助。
> 範圍：臺北市社會局、衛生局、稅捐處，以及衛福部的現金補助、費用減免與權益。假牙補助已在 A.12 重新查證（電話以 A.12 為準）。敬老卡、重陽禮金、老人健保自付額、長照交通接送等**已查證過的項目不重查**，直接引用 [`taipei-elderly-services.md`](taipei-elderly-services.md) B.1、B.3、B.7。輔具中心與視障、聽障服務請看 [`taipei-disability-services.md`](taipei-disability-services.md)。

## 三句話結論

1. **長輩的補助幾乎都看「家庭收入」，不是只看「有沒有低收入戶卡」。** 中低收入老人生活津貼（每月 8,329 或 4,164 元）和身障生活補助（每月 4,049～9,485 元），只要全家平均每人每月收入不超過 39,960 元就能申請，門檻比中低收入戶（29,635 元）寬。所以「不是低收、中低收」的長輩也要列出這兩項，並標成「要看家裡收入」。
2. **線上申辦目前不可靠，主要管道還是「戶籍地區公所社會課＋1999 轉分機」。** 社會局各頁面連到台北服務通（service.taipei）的案件頁，我用真實瀏覽器打開 AI005（中低老人津貼），**回應是 404**。可以確定能線上辦的只有：輔具補助線上通、重陽禮金匯款申請，以及在台北通 App 下載低收／中低收電子證明。App 的主要動作要做成「撥 1999 轉分機」和「顯示同區社會課地址電話」。
3. **家人代辦大多可以，但要帶的東西不同。** 低收、中低收、老人津貼、身障生活補助：帶**代申請人身分證明影本**就可以代填、代簽，頁面沒寫要委託書。停車證、愛心卡、身障保費補助、輔具補助：要**委託書（委任書）**。長照：家人直接打 1966 就能申請。這張對照表就是「家人代辦」功能的內容。

## A. 每項補助細節

### A.1 低收入戶、中低收入戶資格（社會局社會救助科；受理窗口是戶籍地區公所社會課）✅

這是很多補助的前提：長照自付 0%、學雜費減免、假牙、帶狀疱疹疫苗、修繕補助等都要先有這個身分。

- **115 年門檻**（臺北市政府 114-09-26 府社助字第 11431600601 號公告）✅

| 項目 | 低收入戶 | 中低收入戶 |
|---|---|---|
| 全家平均每人每月收入 | ≤ **20,744 元**（最低生活費） | ≤ **29,635 元** |
| 動產（存款＋投資），平均每人 | ≤ 15 萬元 | ≤ 16 萬元 |
| 不動產（全家土地＋房屋） | ≤ 837 萬元 | ≤ 992 萬元 |

- **共同條件**：設籍並實際居住臺北市，最近一年在國內居住超過 183 日 ✅。常見問答的寫法是「出境累計未超過 183 日」，和申請說明頁的措辭不同 ⚠️。
- **全家人口的範圍**：配偶、一親等直系血親、同戶籍或共同生活的其他直系血親、認列扶養免稅額的納稅義務人（社會救助法第 5 條）✅。
- **低收入戶每月金額**（115 年）✅：第 0 類（全戶無收入）每人 20,744 元，第三口起每人 15,317 元；第 1 類每人 15,317 元；第 2 類全戶 7,911 元；第 3、4 類只有兒少加發。每人每月政府救助合計上限 29,500 元。
- **中低收入戶沒有生活費**，只有高中以上學雜費減免 60%、全民健保自付保費補助 50% ✅。
- **應備文件** ✅：申請表；申請人身分證正本（查驗後歸還）；新式戶口名簿（含詳細記事）影本，機關能查到的免附；租賃契約或借住證明；申請人台北富邦銀行或郵局的存摺封面影本；需要時附收入或財產異動證明、診斷證明、身障證明。
- **申請管道**：戶籍地區公所社會課臨櫃（地址電話見 §C.3）✅。社會局諮詢是 1999 轉 1609～1613 ✅。社會局頁面上的線上連結是台北服務通 AI041（低收）、AI040（中低收），內容讀不到 ⚠️。
- **代辦** ✅：應備文件頁原文是「託他人代申請、代填申請表及代為簽名/蓋章/線上簽核者，應檢附代申請人身分證明文件影本」。頁面沒寫要委託書。
- **近年調整**：114 年的舊頁數字比較低，115 年調高。**data.taipei 的〈社會救助補助項目〉資料集還是 109 年的標準（收入 17,005 元），不能用**（見 §D）。
- **台北通**：已有資格的人，登入**台北通金質會員** → 福利身分 → 申請/查看證明 → 我的證書，就可以下載低收／中低收電子證明 PDF。完成金質會員後，資料大約要 1 天才會出現 ✅（[社會局 FAQ](https://dosw.gov.taipei/News_Content.aspx?n=91F35523B74F69AC&sms=87415A8B9CE81B16&s=938031635361912E)，資料更新 115-10-19）。
- **來源**：[低收入戶](https://dosw.gov.taipei/cp.aspx?n=E6D700BD37E78592) ✅、[中低收入戶](https://dosw.gov.taipei/cp.aspx?n=B75CE261826F1C11) ✅（資料更新 114-12-31）、[低收分類 FAQ](https://dosw.gov.taipei/News_Content.aspx?n=91F35523B74F69AC&sms=87415A8B9CE81B16&s=BAA030FB7C91B247) ✅、[中低收 FAQ](https://dosw.gov.taipei/News_Content.aspx?n=91F35523B74F69AC&s=674B8A6A761F5B8C) ✅

### A.2 中低收入老人生活津貼（社會局社會救助科；區公所社會課受理）✅

- **資格**（115 年）：65 歲以上；設籍並實際居住本市，國內居住超過 183 日；未受公費收容安置；全家平均每人每月收入 ≤ **39,960 元**；動產單人家庭 250 萬元，每多一口加 25 萬元；不動產 ≤ 992 萬元；沒有在服刑、羈押或拘禁。
- **金額**：平均每人每月收入 ≤29,635 元的人，每月 **8,329 元**；29,635～39,960 元的人，每月 **4,164 元**；同時領榮民就養給付、但不是低收入戶的人，每月 2,290 元。
- **重點**：**不需要先有中低收入戶身分**，只看家庭收入與財產。
- **和身障生活補助只能擇優領一項** ✅（見 A.4）。
- **應備文件**：大致和 A.1 相同；存摺必須是**申請人本人**的郵局或台北富邦帳戶。
- **申請管道**：區公所社會課；1999 轉 1609～1613。社會局頁面連到台北服務通 AI005，2026-11-07 用 Chromium 打開**顯示「Oops!無法找到此頁面 404」** ⚠️。
- **代辦**：可以，附代申請人身分證明影本 ✅。
- **近年調整**：衛福部 112-09-14 宣布 113 年 1 月起依 CPI 調整，當時的預估值是 8,302／4,151 元。臺北市現行頁面寫 8,329／4,164 元，但**沒找到衛福部的定案公告** ⚠️。App 以臺北市頁面為準。
- 「已列冊的中低收入戶滿 65 歲由社會局主動核發」只出現在搜尋摘要 🔍。
- **來源**：[社會局](https://dosw.gov.taipei/cp.aspx?n=FCF3DAE98DDA289F) ✅（資料更新 115-10-07）、[FAQ](https://dosw.gov.taipei/News_Content.aspx?n=91F35523B74F69AC&s=64A2C16365657374) ✅、[衛福部 112-09-14](https://www.mohw.gov.tw/cp-16-75968-1.html) ✅

### A.3 中低收入老人特別照顧津貼（社會局；老人服務中心受理）✅

- **被照顧的長輩**：已領中低收入老人生活津貼；沒有使用機構安置、居家服務、看護（傭）、日間照顧補助、重病住院看護補助等；ADL 評估為重度以上，**實際由家人照顧**；實際住在戶籍地。
- **照顧者**：16～64 歲；是家庭總收入計算範圍內的家人、出嫁女兒或入贅子及其配偶，或二親等內直系血親卑親屬；沒有全職工作；同樣設籍並住在臺北市。
- **金額**：照顧者每月 **5,000 元**，條件是政府委派的居家服務單位每月到家督導一次 ✅。中央《中低收入老人特別照顧津貼發給辦法》第 5 條也是 5,000 元 ✅。**沒找到「115 年度」的金額公告** ⚠️。
- **注意**：和居家服務（長照照顧服務）**互斥**。App 要提醒：用了長照居服就不能領這項。
- **應備文件**：照顧者和被照顧者的身分證影本、ADL 重度以上證明、照顧者郵局存摺封面影本。
- **申請管道**：各區老人服務中心；1999 轉 **1674**。這個洽辦頁的資料更新是 113-01-19，比較舊 ⚠️。台北服務通 AI032 讀不到 ⚠️。
